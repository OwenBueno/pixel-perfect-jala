# pixel-perfect-jala

Pixel-perfect HTML/CSS replica of the Jala University login design (Figma: [Dev Mode 26](https://www.figma.com/design/g4EYxAHY30riFifn6PdHOn/Dev-Mode-26?node-id=0-1)).

- **No JavaScript** – layout and visuals only.
- Open `index.html` in a browser or run a local server to view.
